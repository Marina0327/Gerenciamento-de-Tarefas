#                                                          Gerenciador de Tarefas (To-Do List) em Python

Este é um projeto simples de **Gerenciamento de Tarefas (To-Do List)** desenvolvido em **Python**, com foco em demonstrar o uso de **Técnicas de Desenvolvimento de Algoritmos** e **estruturas de dados básicas (listas)** em um **console interativo**.

---

## Tecnologias e Algoritmos

### Linguagem
- **Python **

### Estrutura de Dados
- **Lista (list)**: utilizada para armazenar e manipular as tarefas.

---

## Técnicas Utilizadas

O código é dividido em **funções bem definidas**, como:
- `adicionar_tarefa()`
- `visualizar_tarefas()`
- `remover_tarefa()`
- `arquivar_tarefa()`
- `menu_principal()`

Isso torna o código mais **organizado, legível e fácil de manter**.

---

###  Controle de Fluxo
- Utilização de **laço `while`** para manter o **menu principal ativo** até o usuário optar por sair.  
- Uso de **estruturas condicionais `if/elif/else`** para o **controle das operações** escolhidas.

---

###  Tratamento de Erros
- Implementação de **blocos `try-except`** para evitar falhas em entradas inválidas (como valores não numéricos).
- Melhora a **robustez e estabilidade** do programa durante a execução.
